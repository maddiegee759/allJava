6. Find the line with a syntax error.
public class Calculator {
    public static void main(String[] args) {
        int a = 5;
        int b = 2;
        * double result = a / b;
        System.out.println(result);
    }
}

Note: Dividing two integers (`int`) in Java results in an integer division, truncating any decimal part. While not a syntax error, it's a logical error as the result will be 2.0, not 2.5. To get a correct decimal result, at least one operand should be a double, e.g., `(double) a / b`.
